# Dynamic_Broadband_Allocation
This is a home lab setup which virtualises my implementation of a new ISP service approach. This was my dissertation project in University, but I wish to document it here also. It includes the hardware, code, and any virtual machine utilised.

The reason I developed this was because I believe that the current implementation for broadband is inefficient and does not meet the current demands of technology.

For example, if you wanted to increase your bandwidth today, assuming you have a current plan, you would have to either wait out the contract or pay a termination fee. Considering all you wish to do is change your speed to match the ever growing demands of technology, this is unreasonable. Even if you use a pay-as-you-go plan, the termination fees are still extortionate.

As a result, I designed NetNeuronix - an App driven dynamic allocation ISP service that allows for flexible internet service. 

You would download the app on your phone (in this instance you would access a website) which would then let you see your billing and active plans. 

Please see the documentation folder if you wish to learn more about this project!
